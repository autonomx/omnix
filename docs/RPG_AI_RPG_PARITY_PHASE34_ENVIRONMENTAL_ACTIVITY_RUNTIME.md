# Phase 34 — Environmental Activity Runtime

Phase 34 expands the compact Phase 31 activity tuple into deterministic runtime-facing living activity metadata.

Implemented:

- visible activity rows for population, nearby NPCs, local events, factions, hazards, and scene action;
- deterministic activity intensity and actor-group reporting;
- opportunity signals for rumors, events, reputation, conflict, and danger;
- narration guidance embedded into the environmental scene-introduction contract;
- summary-level activity aggregation for report surfaces.

Verification remains gated by GitHub Actions on the implementation PR.
