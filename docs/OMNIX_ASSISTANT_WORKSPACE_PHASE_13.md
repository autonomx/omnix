# Omnix Assistant Workspace Phase 13 — Knowledge and Retrieval System

Phase 13 adds a small library-item layer for workspace and project retrieval surfaces.

## Scope

- Represent workspace library items and text segments.
- Select ready items for context use.
- Scope items to workspace and optional project views.

## Acceptance criteria

- Ready library items are selected deterministically.
- Workspace and project filtering does not leak unrelated items.
- Segment lookup can be derived from selected library items.
