# Phase 41 — Last 10 Debug Payload

Phase 41 expands the live RPG Last 10 turn report as a diagnostic artifact only.

Added:

- per-turn raw result extraction;
- intent diagnostic capture;
- dialogue and NPC handoff capture;
- response source and fallback evidence capture;
- job, stage, and provider timing breadcrumbs;
- report-level stage totals;
- HTML details blocks for inspecting the captured payloads;
- regression coverage for transcript and HTML output.

No gameplay behavior, simulation state, dialogue generation, or response selection behavior is changed by this phase.
