# OWASP ASVS 4.0.3 Level 2 checklist

Status: 2026-10-03, WP-4.11. Every Level 2 requirement of ASVS 4.0.3 (259,
Level 1 included), assessed against this repository with sign-in on (local or
OIDC mode) behind the TLS ingress. Sign-in is off by default by owner decision
(WP-4.1); a deployment without it fails most of V2–V4 and must stay on
loopback (the startup check enforces that). Update a row when the code it
cites changes.

Status meanings: **Pass**, the requirement holds, with the evidence named;
**Fail**, it does not, with the reason; **N/A**, Omnix has no such feature.
