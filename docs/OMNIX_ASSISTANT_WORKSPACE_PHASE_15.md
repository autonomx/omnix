# Omnix Assistant Workspace Phase 15 — Context Visualization Panel

Phase 15 adds pure contracts for the context visualization panel.

## Scope

- Define stable context-panel tabs.
- Summarize included and omitted context sources.
- Surface token budget totals for UI rendering.

## Acceptance criteria

- Context panel tabs are deterministic.
- Summaries expose included, omitted, estimated, and maximum token counts.
- Helpers are pure and independent of UI framework state.
