# Phase 37 — Scheduled Environmental Activity

Phase 37 expands living activity extraction beyond pre-normalized report fields.

Implemented:

- location ambient/current activity extraction;
- NPC activity extraction from turn, state, world, and location schedule-like structures;
- scheduled event extraction from turn, state, world, and location structures;
- location filtering for NPCs and events;
- regression coverage proving scheduled activity reaches the environmental narration contract.

Verification remains gated by GitHub Actions on the implementation PR.
