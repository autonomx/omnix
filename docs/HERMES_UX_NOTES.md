# Hermes UX Notes

This note captures the next interface polish target.

## Current behavior

- Settings can show the current integration state.
- Settings can run a smoke check.
- Agent Chat remains opt-in.
- Normal Chat remains the default path.

## Desired polish

- Keep status and smoke-check output in the same card.
- Avoid creating extra conversation records from Settings checks.
- Show clear error text when the smoke check fails.
- Make backend selection visible in Agent Chat responses.

## Acceptance

A future code slice should update the card behavior once connector writes for that UI change are accepted.
