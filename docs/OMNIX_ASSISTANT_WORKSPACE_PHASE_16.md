# Omnix Assistant Workspace Phase 16 — Modern App Shell

Phase 16 adds pure layout contracts for the assistant workspace app shell.

## Scope

- Define stable layout regions for top bar, navigation, timeline, context panel, and composer.
- Create default layout state.
- Resolve visible regions after panel collapse.

## Acceptance criteria

- Default layout contains all shell regions.
- Collapsed side regions are excluded from visible-region output.
- Layout helpers remain framework independent.
