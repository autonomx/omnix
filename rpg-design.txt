3. Fix top nav placement and ensure all links are available there

The second screenshot’s nav style is correct. The issue is that the appendix links should be part of the top rpg-nav, not local blocks lower down.

Make sure _render_rpg_nav(...) has this structure:

def _render_rpg_nav(primary_links, appendix_links=None):
    appendix_links = appendix_links or []

    def render_links(links):
        items = []
        for target, label in links:
            if not target or not label:
                continue
            items.append(f'<a href="#{escape(target)}">{escape(label)}</a>')
        return "".join(items)

    primary_html = render_links(primary_links)
    appendix_html = render_links(appendix_links)

    appendix_block = ""
    if appendix_html:
        appendix_block = f"""
        <details class="rpg-nav-appendix" open>
          <summary>Appendix Sections</summary>
          <div class="rpg-nav-appendix-links">
            {appendix_html}
          </div>
        </details>
        """

    return f"""
    <nav class="rpg-nav" aria-label="Campaign report sections">
      <div class="rpg-nav-primary">
        {primary_html}
      </div>
      {appendix_block}
    </nav>
    """

Important change from the prior patch:

-<details class="rpg-nav-appendix">
+<details class="rpg-nav-appendix" open>

That makes all section links visible at the top by default, like your second screenshot, while still visually separated from the primary nav.
