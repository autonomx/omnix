Goal

Fix the current 177 state:

1. Quest hooks/facts are mostly firing, but quest_progress_summary is still stale.
2. Player still targets Bran too much after the road transition.
3. “I stop repeating...” became a repeated meta-repair action.
4. Dialogue memory only records 2 exchanges despite many Bran turns.
5. health.progress_quality.ok is false, but top-level gates still pass.
6. Suggested actions still include stale Witness Search / Bran actions after transition.

This patch makes the post-transition state authoritative:

Once the player has reached the road or the Bandit Road hook is active:
  - hard-block Bran/witness-repeat actions
  - force road/track/bridge/wagon/next-lead actions
  - repair “stop repeating...” into concrete road investigation
  - rebuild quest summary from latest state/facts at the final write point
  - include strict health.progress_quality in quality gates
