Bundle M43-M45 — Runtime Story Pack Activation + Campaign Director Bridge v1
GOAL:
Bridge imported/approved story packs into the runtime campaign director safely.

This bundle adds:
- Story pack activation state
- imported story packs can be inactive by default
- active story packs expose escalation rules to campaign director
- inactive packs do not drive escalation
- approved/imported story packs can be activated explicitly
- activation/deactivation is deterministic and bounded
- campaign director evaluates only active story pack rules by default
- story authoring approval/import flow can optionally auto-activate imported packs
- inspector/API payload shows active/inactive imported packs
- manual tests verify inactive packs do not escalate and active packs do

Important:
- Importing a story pack does not automatically mean it drives runtime, unless auto_activate is explicitly requested.
- Campaign director should not consume every imported pack forever without activation gating.
- Activation state is authoritative deterministic simulation state.
- LLM cannot activate packs directly.

+def normalize_story_pack_activation_state(value: Dict[str, Any] | None) -> Dict[str, Any]:

+def list_active_escalation_rule_definitions(
+    simulation_state: Dict[str, Any],
+    *,
+    arc_id: str = "",
+) -> List[Dict[str, Any]]:
+    """Return escalation rules belonging to active imported story packs only.
+
+    Rules imported before activation support may not have source_pack_id metadata.
+    In that case, this function falls back to proposal escalation_rules stored
+    on each active imported story pack.
+    """
+    active_pack_ids = set(list_active_story_pack_ids(simulation_state))
+    if not active_pack_ids:
+        return []
+
+    story_pack_state = simulation_state.get("story_pack_state") if isinstance(simulation_state, dict) else {}
+    imported_packs = story_pack_state.get("imported_packs") if isinstance(story_pack_state, dict) else {}
+    rows: List[Dict[str, Any]] = []
+    for pack_id in sorted(active_pack_ids):
+        imported = imported_packs.get(pack_id) if isinstance(imported_packs, dict) else None
+        if not isinstance(imported, dict):
+            continue
+        proposal = imported.get("proposal") if isinstance(imported.get("proposal"), dict) else {}
+        for rule in proposal.get("escalation_rules") or []:
+            if not isinstance(rule, dict):
+                continue
+            if arc_id and str(rule.get("arc_id") or "") != arc_id:
+                continue
+            copied = dict(rule)
+            copied.setdefault("source_pack_id", pack_id)
+            rows.append(copied)
+
+    # Deterministic order: highest priority first, then rule id.
+    rows.sort(key=lambda row: (-int(row.get("priority") or 0), str(row.get("rule_id") or "")))
+    return rows
