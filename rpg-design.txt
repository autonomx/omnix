Below is N79-N81.1 — Semantic Action Extraction Fix for 100-Turn Eval as a literal apply-this-patch diff spec.

Goal:

Fix 100-turn evaluation action diversity metrics.

Current issue:
  semantic_action == unknown for every turn

Fix:
  read semantic action from all known locations:
    turn_contract.semantic_action
    turn_contract.semantic_action_v2
    turn_contract.resolved_action
    fast_semantic_action
    semantic_action_record
    selected_player_action
    combined background diagnostics/context
    player-agent trace fields

Normalize:
  action kind/type names
  targets like Bran / npc:Bran / Bran (Innkeeper) / innkeeper -> Bran when present NPC context supports it

Result:
  action_diversity_summary should show real semantic actions, not unknown:8

Strict rules:

Evaluation-only patch.
No authoritative state mutation.
No player action rewriting.
No LLM behavior changes.
No quest/NPC/inventory/combat mutation.

+def _clean_target_label(value: Any) -> str:
+    text = _safe_str(value).strip()
+    if not text:
+        return ""
+    # Normalize common id/display forms.
+    if text.lower().startswith("npc:"):
+        text = text.split(":", 1)[1].strip()
+    if "(" in text and ")" in text:

+    text = text.strip(" .,:;[]{}\"'")

+def _normalize_target(value: Any, row: Dict[str, Any]) -> str:
+    text = _clean_target_label(value)
+    if not text:
+        return ""
+    aliases = _present_npc_aliases(row)
+    lower = text.lower()
+    if lower in aliases:
+        return aliases[lower]
+    lower_underscored = lower.replace(" ", "_")
+    if lower_underscored in aliases:
+        return aliases[lower_underscored]
+    if text.lower() in {"none", "unknown", "null"}:
+        return ""
+    return text

+    for value in values:
+        text = _safe_str(value).strip()
+        if text:

+    return ""
