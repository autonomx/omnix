Below is N81.2 — Pre-Turn Background Drain + Future-Turn Advisory Promotion Timing as a literal apply-this-patch diff spec.

Goal:

Background jobs should not rewrite the same authoritative turn, but completed background results should be drained early enough to influence future turns.

Current bad pattern:
  submit turn 1..8 jobs during playable loop
  attach turn 1..8 results only after playable loop ends

Desired pattern:
  start turn N
  drain completed background jobs from turns < N
  attach results to prior rows
  run deterministic promotion/evolution/profile persistence on newly attached results
  carry updated runtime into player-agent context
  then choose turn N action

Strict rules:

Do not block indefinitely.
Do not let LLM output mutate authoritative state directly.
Do not let background result change the already-completed turn contract.
Only deterministic promotion/consumption can affect future-turn runtime context.
Final post-run drain still exists for report completeness.

+def _try_get_combined_background_result(
+    *,
+    pipeline: Any,
+    job_id: str,
+    wait_ms: int = 0,
+) -> Dict[str, Any]:
+    """Best-effort adapter over the background pipeline's existing result API.
+
+    Different local versions of the pipeline have used slightly different
+    method names. Keep this adapter defensive so the timing patch is easy to
+    apply over recent code.
+    """
+    if not pipeline or not job_id:
+        return {}
+
+    wait_seconds = max(0.0, float(wait_ms or 0) / 1000.0)
+    method_names = (
+        "get_completed_result",
+        "get_result_if_done",
+        "try_get_result",
+        "get_result",
+        "await_result",
+    )
+    for name in method_names:
+        method = getattr(pipeline, name, None)
+        if not callable(method):
+            continue
+        try:
+            # Prefer non-blocking/short-timeout forms when supported.
+            try:
+                result = method(job_id, timeout=wait_seconds)
+            except TypeError:
+                try:
+                    result = method(job_id, timeout_seconds=wait_seconds)
+                except TypeError:

+                    except TypeError:
+                        result = method(job_id)
+            result = _safe_dict(result)
+            if result:
+                return result
+        except TimeoutError:
+            return {}
+        except Exception:

+            # real pipeline errors elsewhere.

+def _drain_completed_background_jobs_for_transcript(
+    *,
+    pipeline: Any,

+        "checked": checked,
+        "attached": attached,
