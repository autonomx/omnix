N101.1 Fix — Candidate JSON Truncation / Parse Failure
Goal

Latest result shows:

LM Studio starts returning:
  rpg_narration_candidates_v1

But parser reports:
  parsed_json_ok: false
  parsed_format_version: ""
  parsed_is_candidate_envelope: false

Then runtime falls into misleading old v2 errors:
  invalid_format_version
  missing_narration
  npc_not_object

Most likely cause:

The candidate envelope is being truncated because provider max_tokens is still sized for the old single rpg_narration_v2 payload.

A candidate response is roughly 2x larger because it includes:

primary
safe_fallback

This patch does four things:

1. Increase runtime narration max_tokens for candidate envelopes.
2. Tighten prompt so both candidates are short.
3. Add parse-error diagnostics.
4. Stop reporting old v2 schema errors when candidate JSON is present but incomplete/unparseable.

3. Add parse-error diagnostics to robust JSON extraction

Patch:

src/app/rpg/narration/runtime_narration_contract.py

Add this detailed helper:

def _extract_json_object_with_diagnostics_from_provider_text(text: Any) -> Dict[str, Any]:
    """Extract provider JSON and return parse diagnostics.

    Returns:
      {
        "payload": dict,
        "ok": bool,
        "error": str,
        "strategy": str,
        "raw_length": int,
        "contains_candidate_marker": bool,
        "brace_balance": int,
        "ends_with_brace": bool
      }
    """
    raw = _safe_str(text)
    diagnostics: Dict[str, Any] = {
        "payload": {},
        "ok": False,
        "error": "",
        "strategy": "",
        "raw_length": len(raw),
        "contains_candidate_marker": "rpg_narration_candidates_v1" in raw,
        "brace_balance": raw.count("{") - raw.count("}"),
        "ends_with_brace": raw.rstrip().endswith("}"),
    }

    if not raw.strip():
        diagnostics["error"] = "empty_provider_text"
        return diagnostics

    cleaned = raw.strip().lstrip("\ufeff").strip()

    if cleaned.startswith("```"):
        cleaned = re.sub(r"^```(?:json|JSON)?\s*", "", cleaned).strip()
        cleaned = re.sub(r"\s*```$", "", cleaned).strip()

    try:
        parsed = json.loads(cleaned)
        if isinstance(parsed, dict):
            diagnostics.update(
                {
                    "payload": parsed,
                    "ok": True,
                    "strategy": "direct",
                    "error": "",
                }
            )
            return diagnostics
        diagnostics["error"] = "json_root_not_object"
    except Exception as exc:
        diagnostics["error"] = f"direct:{type(exc).__name__}:{exc}"

    start = cleaned.find("{")
    end = cleaned.rfind("}")
    if start >= 0 and end > start:
        candidate = cleaned[start : end + 1].strip()
        try:
            parsed = json.loads(candidate)
            if isinstance(parsed, dict):
                diagnostics.update(
                    {
                        "payload": parsed,
                        "ok": True,
                        "strategy": "first_brace_to_last_brace",
                        "error": "",
                    }
                )
                return diagnostics
            diagnostics["error"] = "slice_root_not_object"
        except Exception as exc:
            diagnostics["error"] = f"slice:{type(exc).__name__}:{exc}"

    start = cleaned.find("{")
    if start < 0:
        diagnostics["error"] = diagnostics["error"] or "missing_open_brace"
        return diagnostics

    depth = 0
    in_string = False
    escape = False
    for index in range(start, len(cleaned)):
        char = cleaned[index]

        if escape:
            escape = False
            continue

        if char == "\\" and in_string:
            escape = True
            continue

        if char == '"':
            in_string = not in_string
            continue

        if in_string:
            continue

        if char == "{":
            depth += 1
        elif char == "}":
            depth -= 1
            if depth == 0:
                candidate = cleaned[start : index + 1].strip()
                try:
                    parsed = json.loads(candidate)
                    if isinstance(parsed, dict):
                        diagnostics.update(
                            {
                                "payload": parsed,
                                "ok": True,
                                "strategy": "balanced_braces",
                                "error": "",
                            }
                        )
                        return diagnostics
                    diagnostics["error"] = "balanced_root_not_object"
                except Exception as exc:
                    diagnostics["error"] = f"balanced:{type(exc).__name__}:{exc}"
                return diagnostics

    diagnostics["error"] = diagnostics["error"] or "unterminated_json_object"
    diagnostics["brace_balance_after_scan"] = depth
    diagnostics["in_string_after_scan"] = in_string
    return diagnostics

Then keep compatibility helper:

def _extract_json_object_from_provider_text(text: Any) -> Dict[str, Any]:
    return _safe_dict(
        _extract_json_object_with_diagnostics_from_provider_text(text).get("payload")
    )

8. Add test proving parse failure does not emit old v2 errors

If the provider-response handling function is hard to unit-test directly, add a small helper.

Patch:

src/app/rpg/narration/runtime_narration_contract.py

Add:

def _validate_parsed_provider_payload_or_parse_failure(
    *,
    parsed_payload: Dict[str, Any],
    provider_call_diagnostics: Dict[str, Any],
    player_action: str,
) -> Dict[str, Any]:
    contains_candidate_marker = bool(
        _safe_dict(provider_call_diagnostics).get("parsed_json_contains_candidate_marker")
    )
    parsed_json_ok = bool(
        _safe_dict(provider_call_diagnostics).get("parsed_json_ok")
    )

    if contains_candidate_marker and not parsed_json_ok:
        parse_error = _safe_str(
            _safe_dict(provider_call_diagnostics).get("parsed_json_error")
        )
        return {
            "ok": False,
            "errors": [
                "provider_json_parse_failed_candidate_envelope",
                parse_error or "unknown_parse_error",
            ],
            "payload": {},
        }

    return validate_narration_payload(
        parsed_payload,
        player_action=player_action,
    )

Then replace validation call sites with:

)

from app.rpg.narration.runtime_narration_contract import (
