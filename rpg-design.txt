N89.3 — Generic Handoff Lead Quality + Semantic Action Rotation
Goal

Fix run 188 without hardcoding the tavern/witness/road scenario.

N89.2 fixed state authority and handoff activation, but the generic handoff created a low-information lead:

Investigate Lead: toward
I follow up on the lead: toward.

Then action selection repeated that same handoff action 19 times.

This patch adds a scenario-agnostic handoff framework:

1. Reject low-information leads.
2. Prefer concrete multi-token entities/places/items/factions/events.
3. Generate semantic action variants for any lead.
4. Rotate handoff actions when one repeats.
5. Track handoff semantic action history.
6. Mark generic handoff progress from distinct future semantic actions.
7. Complete/advance handoff after enough distinct meaningful actions.

No scenario-specific strings like Bran, witness, tavern, Bandit Road, bridge, or road should be required.

+def _is_low_information_lead_label(label: str) -> bool:
+    label = " ".join(_safe_str(label).strip().split())
+    if not label:
+        return True
+    norm = _norm(label)
+    raw_tokens = [token for token in norm.split() if token]
+    content_tokens = _lead_content_tokens(label)
+
+    if len(raw_tokens) <= 1:
+        return True
+    if not content_tokens:
+        return True
+    if len(content_tokens) == 1 and content_tokens[0] in LOW_INFORMATION_LEAD_TOKENS:
+        return True
+
+    # Generic phrases like "the clue", "the evidence", "the trail" are not a
+    # good handoff subject unless paired with a concrete entity/place/item.
+    if len(raw_tokens) <= 3 and all(
+        token in LOW_INFORMATION_LEAD_TOKENS or token in LEAD_CONNECTOR_TOKENS
+        for token in raw_tokens
+    ):
+        return True
+
+    return False
+
+
+def _lead_specificity_score(label: str) -> int:
+    label = _safe_str(label)
+    content_tokens = _lead_content_tokens(label)
+    raw_tokens = [token for token in _norm(label).split() if token]
+    score = 0
+    score += min(len(content_tokens), 6) * 10
+    score += min(len(raw_tokens), 8) * 2
+    if any(ch.isupper() for ch in label):
+        score += 10
+    if any(char.isdigit() for char in label):
+        score += 5
+    if len(content_tokens) >= 2:
+        score += 15
+    if _is_low_information_lead_label(label):
+        score -= 100
+    return score
