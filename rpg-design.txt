Bundle M40-M42 — Story Authoring Inspector UI + Pending Proposal Review Panel v1
GOAL:
Add a visible runtime/inspector review surface for authored story proposals.

This bundle connects M37-M39 GM approval state to the legacy RPG UI/inspector:
- fetch pending authored proposals for the current RPG session
- show pending proposal cards in a bounded review panel
- show proposal summary, title, lore/arcs/events/rules counts
- approve pending proposal
- reject pending proposal with reason
- show approval history/debug
- never import on draft alone
- approval/rejection actions call deterministic backend endpoints
- UI must not mutate story state directly
- manual tests validate backend UI payloads and API behavior with full debug

This assumes you already added the optional M37-M39 API routes or equivalent backend functions. If those API routes were skipped, this bundle includes a small stable payload layer and FastAPI endpoints.

+async function postStoryAuthoring(endpoint, payload) {
+    const response = await fetch(endpoint, {
+        method: "POST",
+        headers: {"Content-Type": "application/json"},
+        body: JSON.stringify(payload),
+    });
+    const text = await response.text();
+    let data = {};
+    try {
+        data = text ? JSON.parse(text) : {};
+    } catch (err) {
+        throw new Error(`Invalid JSON from ${endpoint}: ${text.slice(0, 200)}`);
+    }
+    if (!response.ok) {
+        throw new Error(data?.detail || data?.error || data?.reason || `HTTP ${response.status}`);
+    }
+    return data;
+}
