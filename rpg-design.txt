Below is N73-N75.10.1 — Journal Narration Source + Fragment Cleanup as a literal apply-this-patch diff spec.

Goal:

1. Feed the journal useful narration/result prose from autoplay rows.
2. Stop journal entries from using broken/truncated action fragments.
3. Prefer narration/NPC line for “What I learned” and “What changed.”
4. Keep deterministic, non-LLM journal generation.
5. Keep quest-derived “Next” section.

Strict rules:

Journal generation remains deterministic.
No LLM journal authoring.
No authoritative state mutation.
No quest/inventory/currency/combat/location mutation.
Only summarize already-known turn facts.

+    text = _safe_str(value).strip()

+    if len(words) <= 2 and not text.endswith((".", "!", "?")):
+        return True
+
+    # Broken fragments often have no leading verb/subject and include ellipses.
+    if "…" in text or "..." in text:
+        if len(words) < 8:
+            return True
+        if text.count("…") + text.count("...") >= 2:
+            return True
