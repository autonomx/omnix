N88.5.1 — Pre-Turn Advisory Promotion Fast Path + Slow-Path Guard
Why this is needed

The run is slow because pre_turn_deferred_advisory_promotion is blocking the main autoplay loop for tens of seconds to minutes:

turn 13: pre_turn_deferred_advisory_promotion elapsed_ms=43093
turn 14: pre_turn_deferred_advisory_promotion elapsed_ms=87891
turn 15: pre_turn_deferred_advisory_promotion elapsed_ms=185704

The actual runtime turn execution is only around 38–41ms, player-agent calls are around 3s, and background provider calls are around 5–6s, so this is deterministic advisory promotion work, not LM Studio/provider latency.

The current pre-turn promotion path still does expensive work:

load_profiles_into_row_runtime(...)
consume_accepted_advisory_projections(...)
deepcopy/merge large runtime_state
promotion/evolution bookkeeping

For pre-turn incremental promotion, we only need lightweight candidate promotion so the next turn can see recent advisory state. Full NPC evolution/profile loading can wait until final artifact/report processing.
