N81.2.6.2 — Incremental Pre-Turn Advisory Promotion State Compaction

This fixes the remaining stall where bounded pre-turn promotion still becomes slow around turn 15/16. The last run proves the slow stage is still pre_turn_deferred_advisory_promotion, not LM Studio/player-agent/runtime/final drain. Early turns improved to 6ms / 14ms, but later promotion still grows to tens of seconds/minutes because the bounded window seeds from a huge carried runtime state.

Goal
Pre-turn promotion should only process newly attached rows/candidates.

It must not:
  reprocess already-promoted rows
  deepcopy full historical deferred_advisory state
  carry unbounded accepted/rejected/pending/candidate lists
  persist NPC profile files during pre-turn

Final report promotion remains full and persistent.
